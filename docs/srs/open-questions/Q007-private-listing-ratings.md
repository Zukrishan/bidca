# Q007 — Private listings: ratings or not?
Status: **Decided — provisional default (26 Oct 2026)**, chosen by us so building can continue; the client may change it, and a change is just a new decision row in `docs/ASK-NOTES.md`.

- **No ratings** on private listings (L186 is marked Important).
- Private completed deals **do not count** toward the verified badge or tiers (otherwise friends could inflate them).
- Private listings **still need admin approval** (AGENTS.md rule; the source is silent).
- Invite links expire when the listing ends; invitees still need a BidCa account to bid.
