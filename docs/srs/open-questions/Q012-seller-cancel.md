# Q012 — Can sellers cancel a listing?
Status: **Decided — provisional default (26 Oct 2026)**, chosen by us so building can continue; the client may change it, and a change is just a new decision row in `docs/ASK-NOTES.md`.

- **Sellers can cancel their own listings.** With no bids: no penalty. With one or more bids: allowed, but it triggers the suspension in Q010, and every bidder is notified.
- Cancelling needs a confirmation step that states the penalty.
- Pending (not yet approved) listings can be withdrawn freely. Admins can always remove listings.
