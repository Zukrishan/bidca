# 1. Scope

**Purpose.** A trusted, local online auction and fixed-price marketplace for BC residents, reducing
fraud through BC-only registration, admin-approved listings and manual ID verification.

**Users.** Buyer, Seller (same account), Admin.

**In scope:** timed auctions (24/48/72h) with reserve, proxy, sniper and Buy-It-Now; fixed-price
listings with Best Offer; watchlist and saved searches; notifications (in-app + email); ID
verification; seller feedback/ratings; admin moderation (listings, users, verifications, reports);
real-time bid updates; SEO-indexable public listing pages.

**Out of scope (until decided):** payment processing / escrow (Q004), native mobile apps,
automated ID verification, AI fraud detection, bilingual EN/FR (Q005).
